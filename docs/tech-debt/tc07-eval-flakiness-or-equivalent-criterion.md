# TC-07 eval flake: judge rejects "equivalent" template rewrites

- **Area:** `tests/superset/` evaluation harness, TC-07 (Split "It's not X. It's Y." pattern)
- **Severity:** moderate
- **Discovered:** 2026-09-29 during work adding llm-cliche-highlighter patterns to the skill; reproduced twice in one session, then traced in the harness's own history
- **Root cause:** Fixture criterion 4 in `tests/superset/fixtures/tc07-split-its-not.txt` reads "The rewrite uses the template: '[Y] matters more than [X].' or equivalent." The "or equivalent" clause is not operationally defined, so the judge flips between strict (literal phrase required) and lenient (any positive superiority sentence counts) readings between runs. The executing agent under `skills/ai-output-humanizer/SKILL.md` also ignores the mandatory REWRITE TEMPLATE paragraph (SKILL.md §Final scan, item 3/template) in a subset of runs, producing contrast phrasings like "Vocabulary gets the attention, but the handoffs are what hold everything together" or "Writers obsess over vocabulary when structure is what actually carries the argument." Criteria 1-3 (pattern actually fixed, audits performed) always pass; only criterion 4 toggles.
- **Impact:** The suite exits non-zero intermittently with no code change, which blocks the pass^k gate and hides real regressions behind known flake. Harness history shows the flake predates the 2026-09-29 change: sessions 78477BEB, 798F5840, EE003BE1, F5F50ED5 (2 fails each), 5D680E00, 9CF44DD6, CBFC731D, 72D8EFEE (1 fail each), and five 3/3-pass sessions.
- **Fix approach:** Either (a) operationalize "equivalent" in the fixture — e.g. "or a single positive sentence comparing the two things without negation structure (for example: '[Y] is what actually carries/premotes/carries the argument')"; the judge prompt is generic, so the operational definition must live in the fixture criteria text. Or (b) harden the skill-side instruction by making the REWRITE TEMPLATE paragraph an absolute output requirement with a pre-delivery checklist bullet, raising literal-template compliance per run. (a) preserves writing quality; (b) raises determinism but forces an awkward phrasing.
- **Risk:** Not fixed inline because editing a test fixture to make a failing suite pass is test-gaming unless scoped deliberately; the SKILL.md-side fix trades fix-quality determinism against rewrite naturalness, which is an operator call. A one-off session change is also confounded by the k=3 trial variance (need multiple sessions to measure).
